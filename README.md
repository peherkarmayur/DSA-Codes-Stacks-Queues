## 📌 Overview
This repository contains the C++ implementations of Stacks and Queues as part of the Unit-IV CCE II activity. The objective of this repository is to demonstrate fundamental data structure operations and maintain source code using Git version control.

## 🚀 Implementations Included
The repository includes the following four mandatory operations:
1. **Stack using Array:** Implements `push()`, `pop()`, `peek()`, and `isEmpty()` using a static array.
2. **Queue using Array:** Implements `enqueue()`, `dequeue()`, `front()`, and `rear()` using a static array.
3. **Stack using Linked List:** Dynamic memory allocation for stack operations to avoid overflow.
4. **Queue using Linked List:** Dynamic queue implementation using pointers.
